Nova

Lance une commande, surveille-la, redémarre-la à la volée.

Installation

curl -fsSL https://raw.githubusercontent.com/Ekith/nova/release/install.sh | bash

Installer une version précise

Pour figer l'installation sur une version donnée plutôt que la dernière release (voir la liste des versions) :

curl -fsSL https://raw.githubusercontent.com/Ekith/nova/release/install.sh | bash -s -- <version>

Utilisation

Une fois installé :

nova <commande à lancer>
ToucheAction
RRedémarrer le processus
KArrêter nova
CEffacer la console
NNettoyer puis redémarrer le processus

Gestion

CommandeAction
nova --upgrade / -uMet à jour nova vers la dernière version
nova --uninstallDésinstalle nova
nova --version / -vAffiche la version installée
